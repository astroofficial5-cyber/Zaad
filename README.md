- مواقيت اليوم والغد بحسب المدينة أو الإحداثيات والمنطقة الزمنية، مع مصدر Aladhan ونسخة محلية لنفس اليوم عند توفرها.

- مجموعة جزئية: خمسة أذكار بعد الصلاة، وثلاثة للصباح وثلاثة للمساء. النصوص من كتاب حصن المسلم للقحطاني، نسخة رسالة الحرمين، مع روابط ومراجع وملاحظات العدد. ليست مجموعة أذكار كاملة ولا تخريجاً حديثياً مستقلاً.
- إعدادات الحساب والمظهر والعدادات محفوظة على الجهاز.

## التشغيل
يتطلب Node.js وnpm. من مجلد المشروع:

```bash
npm ci
npm test
npm run dev
```

لبناء الموقع الثابت:

```bash
npm run build
```

الناتج في `out`. افتحه عبر خادم محلي، وليس بالنقر على index.html وحده. لا تنشر قبل مراجعة الإعدادات والمحتوى والحقوق.
